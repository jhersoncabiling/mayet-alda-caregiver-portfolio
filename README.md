# Mayet A. Alda — Caregiver Portfolio V1

A separate React + Vite + Tailwind CSS caregiver portfolio, designed for Netlify.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Netlify

Import this project from GitHub or upload the `dist` folder to Netlify. Build command: `npm run build`; publish directory: `dist`.

## Content and photos

Edit `src/data.js` for profile, skills, and experience. Photos are in `public/images/`.

Version 1 intentionally contains no certifications, résumé, or download functionality. Future features can be added as independent components without restructuring existing sections. Hospital names refer to private patient care settings, not direct hospital employment.
